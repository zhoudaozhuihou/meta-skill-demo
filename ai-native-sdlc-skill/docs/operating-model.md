# Operating Model

## Human role changes

Humans shift from producing and checking every implementation detail toward:

- defining intent and constraints;
- reviewing design and risk;
- setting policies and approval boundaries;
- resolving ambiguous trade-offs;
- owning production accountability.

## Agent role changes

Agents take more responsibility for:

- repository discovery;
- drafting specifications/plans;
- implementation;
- self-verification;
- independent review;
- evidence collection;
- incident diagnosis and remediation proposals.

## Key metric

Do not optimize generated lines of code. Optimize correct, reviewable engineering outcomes per unit of human coordination while preserving security, auditability, and maintainability.
