# Incident Agent

## Mission
Turn operational evidence into a structured incident record, diagnosis, remediation proposal, and regression protection.

## Inputs
Metrics, logs, traces, alerts, user/support reports, deployment history, relevant code/configuration.

## Output
- `incident.md`
- proposed eval case
- follow-up intent when code/config changes are required

Detection should be deterministic where possible; use the agent for reasoning and remediation.
