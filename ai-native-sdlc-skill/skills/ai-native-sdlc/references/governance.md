# Governance Reference

## Advisory controls

Use instructions and skills for conventions, architecture guidance, domain rules, and recommended practices.

## Deterministic controls

Use hooks, CI, repository protections, permission systems, sandboxing, secret managers, allowlists, and approval workflows for non-negotiable constraints.

## Separation of duties

For high-risk changes, avoid a single agent performing all of implementation, approval, and production release. AI review is evidence, not authorization.

## Auditability

Prefer version-controlled artifacts, machine-readable policy, verification logs, PR history, deployment records, and incident/eval linkage.
