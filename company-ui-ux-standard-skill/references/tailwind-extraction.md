# Tailwind Extraction

Inspect:

```text
tailwind.config.js
tailwind.config.cjs
tailwind.config.mjs
tailwind.config.ts
```

Also inspect Tailwind CSS-first theme configuration.

Useful sections include colors, fontFamily, fontSize, fontWeight, spacing, borderRadius, boxShadow, screens, zIndex, animation and transition.

Tailwind config can contain executable JavaScript. Static extraction may be incomplete. Record unresolved dynamic sections instead of guessing.
