# UX Mining

Behavioral patterns require behavioral evidence.

Inspect:
- form schemas and messages;
- loading branches;
- Suspense/skeletons;
- empty states;
- error boundaries;
- toast calls;
- confirmation dialogs;
- filters;
- pagination;
- keyboard/focus behavior.

Represent each UX rule as:

```text
Pattern
Trigger
Expected behavior
Evidence
Exceptions
Confidence
```
