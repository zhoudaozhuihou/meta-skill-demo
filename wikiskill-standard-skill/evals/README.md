# WikiSkill Evals

These evals test the meta-skill itself, not a specific downstream domain.

Recommended regression categories:

1. raw traces remain immutable;
2. Wiki persists after rejected skill proposals;
3. rejected proposals are recorded;
4. candidate skill is accepted only when validation improves;
5. proposer does not repeat a rejected proposal without new evidence;
6. inference agent does not receive Wiki by default;
7. generated skills contain standard frontmatter;
8. `PURPOSE.md` links skills back to motivating patterns.
